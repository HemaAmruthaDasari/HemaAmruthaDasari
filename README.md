## 🚀 Projects

### 🏥 WhiteCoats – Healthcare CRM Application
A subscription-based Healthcare CRM platform designed to market doctors based on selected service plans.

- Designed Controller–Service–Repository layered architecture using **Spring Boot** and **Hibernate/JPA**
- Configured **JWT**-based authentication and role-based authorization using **Spring Security**
- Built role-based modules for Agents, Doctors, and Employees for structured access control
- Integrated **Apache Kafka** for event-driven notifications and real-time workflows
- Designed and optimized **MySQL** schemas for doctor profiles, subscriptions, and interaction history
- Deployed via **Docker** containers with automated **Jenkins CI/CD** pipelines
- Implemented centralized exception handling, input validation, and structured logging

**Tech:** `Java` `Spring Boot` `Spring Security` `JWT` `Hibernate` `MySQL` `Apache Kafka` `Docker` `Jenkins` `Postman`

### 🌾 AgriConnect – Farm-to-Buyer Marketplace Platform
A marketplace connecting farmers directly with retailers and wholesalers, eliminating intermediaries.

- Developed REST APIs for produce listings with pricing, harvest date, and quality tracking
- Designed user modules for **Sellers, Buyers, and Facilitators** with Spring Security-based role access control
- Integrated public market price APIs for **live reference pricing**
- Designed scalable **MySQL/PostgreSQL** schemas optimized for high-volume marketplace data
- Built secure authentication, input validation, messaging, and rating systems
- Managed codebase and CI/CD workflows using **Git**, **Maven**, and **Jenkins**

**Tech:** `Java` `Spring Boot` `Spring Security` `REST APIs` `PostgreSQL` `Apache Kafka` `Maven` `Git`
